# L3D: 3D / time and CAD / CAE

Sources: `docs/sources.md`.
Check: `tests/run3d.sh` (builds `.bin/mojo-cv3d`, runs every row of `tests/cases3d/*.txt` against the numpy oracles in
`tools/oracle3d.py` through `tools/check3d.py`). Speed: `docs/bench3d.md` (`tools/bench3d.py`). Real recording:
`tools/e2e3d.py VIDEO`.

CLI: `mojo-cv3d OP OUT IN... [k=v]`; `src/mojocv/cli3d.mojo` exports `dispatch3d(args) -> Bool` for `src/main.mojo` and also
has its own `main`. Every op declares its input count and option names; anything else raises. Data is `.mcv`
(`src/mojocv/mat.mojo`): clouds N x 3 float64, cells M x 3 int32, volumes n x n x n as rows = cols = ch = n.

| module | ops | what it does |
|---|---|---|
| voxel | voxelize, unvoxelize, occupied | point to integer cell + residual in [0,1) and back; distinct sorted cells |
| octree | ohash, odiff, static | Zobrist-hashed sparse octree; diff and static/moving split skip equal-hash subtrees |
| align | umeyama | closed-form similarity (c, R, t) with a Jacobi 3x3 SVD; collinear input raises |
| wavelet | haar3f, haar3i, haar3c | orthonormal 3D Haar, thresholded compression (squared error = dropped energy) |
| desc3d | describe, match | 64-bit descriptors from neighbour-triple handedness, threaded popcount matcher |
| tapvid | tapvid | APD, OA, AJ of TAPVid-3D |
| phasecorr | phasecorr | mixed-radix FFT phase correlation, exact sub-pixel peak |
| burst | burst | register by phase correlation (or given shifts), bilinear splat to a finer grid |
| nurbs | nurbs_fit, nurbs_eval | clamped uniform B-spline / NURBS surface, point and unit normal |
| mesh | mesh | voxel boundary to watertight outward triangles, Euler checked |
| glb | glb, glb_read | glTF 2.0 binary writer (POSITION, NORMAL, COLOR_0, indices) and strict reader |
| step | step, step_surface, step_read | STEP AP242 faceted solid / B-spline surface writer, strict reader |
| cae | stress, colormap | von Mises, hydrostatic, principal values, max shear; blue-to-red map |

## Design decisions

- **Cell hash is mixed.** Raw `Kx[x] ^ Ky[y] ^ Kz[z]` cancels for the four corners of any axis-aligned rectangle of
  cells, so a real change had no effect on the root hash. The cell hash is `splitmix(Kx ^ Ky ^ Kz)`; node hashes are
  still the XOR of their children. Mutant run: without the outer mix `odiff_rect` returns 0 cells.
- **The 1% bar** is measured as nodes compared in the diff against the 8^depth cells of a dense scan: 35 of 262144
  (0.013%) for one added cell in a 64^3 scene. Building the tree (210 us) costs more than filling a dense grid
  (18 us) at this size, so the win is the diff, not a per-frame rebuild.
- **Descriptors** use the sign of a triple product of three neighbour vectors. A dot-product sign test gave 70% one-bits and
  6 of 100 points sharing a descriptor. Mirroring the cloud complements every bit.
- **TAPVid-3D**: the equations did not render in the crawled page, so the metrics follow the TAP-Vid definitions the
  paper extends (header of `tapvid.mojo`). Thresholds {1,2,4,8,16} px projected to depth, or fixed
  {1,4,16,64,256} cm. The paper's median depth rescaling is a pre-step, not included.
- **Phase correlation** reads the fraction off the Dirichlet kernel, exact for a periodic shift (cv2's centroid is not).
  On real decimated frames that are not pure translations the estimate is off by ~0.1 px (docs/bench3d.md, e2e A).
- **Mesh**: corners are welded along lattice edges only, so cells touching at an edge or a point get separate
  vertices. A 4-quad edge whose end vertices stay joined through other cells is switched to the cross pairing.
- **STEP** reader names any entity outside `KNOWN`; `lenient=1` skips them. No CAD kernel is installed, so the
  independent check is a second Part 21 parser in `tools/oracle3d.py`.
- **GLB**: the Khronos validator is not installed; the independent check is the numpy parser in `tools/oracle3d.py`
  plus a Blender 5.2 import (`tools/blender_glb_check.py`, run by hand, not in CI).
