# mojo-cv v0.1.2

**Released:** 2026-11-04 · **Commit:** `935554f` · **Previous:** [v0.1.1](v0.1.1.md)

## What it does

<!-- Stable description of the program. Carried forward from the previous note; edit only when the product itself changes.
     3 to 6 lines: what it is, who uses it, where it runs (URL/port/binary), how to start it. -->
OpenCV-style computer vision in Mojo on the CPU, with 3D, CAD and calibration helpers. Each op is checked against cv2 5.0 (2D) or a numpy, brute-force or closed-form oracle (3D) on the same input. A library (`from mojocv.imgproc import ...`) and a command-line tool (`mojo-cv OP OUT IN... [k=v]` on `.mcv` files).

## Highlights

- `StereoSGBM` at 1080p with 128 disparities peaks at 1.5 GB instead of 11.7 GB, with the same output byte for byte.
- `cvtColor` BGR to RGB no longer writes into the next row for widths 9, 10, 17, 18, 25, 26, ...; the gray and
  YCrCb paths no longer read past the row.
- Malformed input raises an error instead of crashing: a `.mcv` header larger than its data, a short file, glb
  accessors out of bounds, and mismatched arguments to remap, blobFromImage, HOGScores, Farneback flow, bfmatch and
  knnmatch.
- The package precompiles (`mojo precompile src/mojocv`), so the conda recipe builds; it builds on Mojo 1.3
  nightly too.

## Changes

### Added
- `recipe.yaml` (conda package `mojo-cv`), `docs/design.md`.
### Changed
- `StereoSGBM` keeps one uint16 cost volume and rolling path rows; `blockSize` above 16 now raises.
- The 3D command-line entry moves to `tools/cli3d.mojo` (`mojo build -I src tools/cli3d.mojo`).
### Fixed
- `cvtColor` SIMD blocks stay inside their row (bgr2rgb, bgr2gray, rgb2gray, YCrCb).
- `Mat.load` checks the header size against the file before it allocates; a short `.mcv` file or a missing argument
  raises instead of aborting.
- `Rng.sample` raises when n < k instead of looping forever.
- `threshold` saturates `maxval` to the dtype's range.
- `ransac_iters` returns the cap when the inlier share vanishes (it returned a large negative number).
- `remap`, `blobFromImage`, `HOGScores`, `calcOpticalFlowFarneback`, `bfmatch` and `knnmatch` check their
  inputs' shapes and raise on a mismatch.
- glb accessor bounds cannot wrap.
- Builds on Mojo 1.3.0.dev2026110305 as well as 1.2.0.
