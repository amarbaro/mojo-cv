## What it does

<!-- Stable description of the program. Carried forward from the previous note; edit only when the product itself changes.
     3 to 6 lines: what it is, who uses it, where it runs (URL/port/binary), how to start it. -->
OpenCV-style computer vision in Mojo on the CPU, with 3D, CAD and calibration helpers. Each op is checked against cv2 5.0 (2D) or a numpy, brute-force or closed-form oracle (3D) on the same input. A library (`from mojocv.imgproc import ...`) and a command-line tool (`mojo-cv OP OUT IN... [k=v]` on `.mcv` files).

## Highlights

<!-- 1 to 5 bullets a user would notice. Lead with the benefit, not the implementation. -->
- `resize` with `interp=1` on uint8 is now cv2's fixed-point linear resize, bit exact (the comparison bar goes from max difference 1 to 0).
- `cv_circle_outline` thick lines: cv2's `Line2` plots its first endpoint, so the missing tip pixels in five measured segments are gone.

## Changes

### Changed
- uint8 linear `resize` follows cv2's integer arithmetic (tests/cases `imgproc.txt`, `resize_general.txt` and `tools/fastpath_check.py` now demand maxdiff 0).
### Fixed
- `_line2` plots cv2 Line2's first endpoint (five `cv_circle_outline` rows in `tools/fastpath_check.py`, found by a 1500-line sweep against `cv2.line`, 9 hits).
